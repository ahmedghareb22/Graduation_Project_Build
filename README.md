# 🏛️ Virtual Egyptian Museum

An immersive web experience showcasing Ancient Egyptian history with an interactive library, holographic hieroglyphics tool, and Unity 3D integration.

## 🚀 Getting Started

### Prerequisites

- Docker & Docker Compose

### Run the project

```bash
docker-compose up -d --build
```

Access the museum at [http://localhost:8080](http://localhost:8080)

## 🛠️ Management
Access the stable interactive API documentation at [http://localhost:8080/docs.html](http://localhost:8080/docs.html).

## 📁 Project Structure

- `public/`: Frontend static assets (HTML/React/Unity/CSS).
- `backend/`: Python Flask API and SQLite database.
- `nginx.conf`: Reverse proxy and static file server configuration.

## 🛠️ Management
Access the stable interactive API documentation at [http://localhost:8080/docs.html](http://localhost:8080/docs.html).

## 👑 Main Features

- **Library of Kings**: React-based grid with historical pharaoh data.
- **Holographic Hieroglyphics**: Authentic name writing tool.
- **Royal Archive**: Admin panel for managing museum records.
